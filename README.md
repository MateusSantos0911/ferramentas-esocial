# Ferramentas eSocial · PGE-RJ

Aplicação estática (página única, 100% no navegador) com três ferramentas de conferência dos eventos periódicos do eSocial:

1. **Conferência de INSS (RGPS)** — folha × eSocial (S-5001) e cálculo da DCTFWeb.
2. **Confronto eSocial × ERGON** — classifica cada servidor no evento correto (S-1200 / S-1202 / S-1207) e separa as divergências reais das justificadas.
3. **Controle de envio dos eventos** — esperados (folha) × gerados (JSONs): mostra o que falta gerar/enviar.

O acesso é por login. Os arquivos importados são processados **somente neste navegador** — nada é enviado a servidores externos. **Nenhum dado pessoal fica neste repositório.**

Hospedado no GitHub Pages.
